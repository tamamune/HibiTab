# タブ整理＆日報（Tab Archive Diary）

一定時間触っていない「放置タブ」を自動でアーカイブして閉じ、その日に開いたページを**日付ごとの日報**として Google ドライブに保存する Chrome 拡張機能です。
お気に入り・よく見る・アーカイブのタブもまとめて管理できます。

## 機能

| 画面 | できること |
| --- | --- |
| **開いている** | 全ウィンドウのタブ一覧。放置時間・「あと◯分で整理」を表示。☆お気に入り / 🛡保護 / 📦アーカイブして閉じる / ✕閉じる。「放置タブを整理」で一括アーカイブ |
| **お気に入り** | ☆で登録したページ。URL 直接追加、並べ替え、名前変更、すべて開く。お気に入りのページは自動で閉じない（設定で変更可） |
| **よく見る** | 閲覧回数ランキング（今日 / 7日 / 30日 / 90日 / 全期間、ページ単位 / サイト単位） |
| **アーカイブ** | 自動・手動で閉じたタブを日付ごとに保存。クリックで復元、日単位で一括復元・削除 |
| **日報** | 日ごとの閲覧ページ（時系列）、よく見たサイト、アーカイブしたタブ。Markdown コピー / ダウンロード / Drive 保存 |
| **設定** | 放置時間（初期値 180 分＝3時間）、保護ルール、保存期間、Google ドライブ連携、データの書き出し |

- 放置チェックは 5 分ごと。固定タブ・音声再生中・お気に入り・保護ドメイン・🛡 で保護したタブは閉じません。
- **表示中のタブも対象**（初期値オン）: 各ウィンドウで表示中のタブも、使われていなければ閉じます。前面のウィンドウで PC を操作している間は時間が進まず、ウィンドウが裏にあるとき・PC を 5 分以上操作していないとき・画面ロック中に放置時間が進みます。ウィンドウのタブがすべて対象になるとウィンドウごと閉じます。設定でオフにすると、表示中のタブは閉じません。
- **ウィンドウ単位の保護**: 「開いている」画面の各ウィンドウ見出しにある「🛡 このウィンドウを保護」で、そのウィンドウのタブを丸ごと自動整理の対象外にできます。ウィンドウ ID はブラウザを再起動すると変わるため、保護は再起動で解除されます。
- **Vivaldi 対応**: Vivaldi でもそのまま動きます（タイトル・URL は通常どおり取得）。Vivaldi の Web パネルは通常のタブではないため、一覧・自動整理・日報から除外します。
- ブラウザ再起動直後は、復元されたタブの放置時間をリセットします（起動直後に一斉に閉じられないように）。
- 上部の検索欄で、どの画面でもタイトル・URL を絞り込めます。
- ショートカット: `Alt+Shift+A` でポップアップ。右上の ⤢ で大きな画面で開けます。

## インストール

1. このリポジトリをダウンロード（`git clone https://github.com/tamamune/Tab-Archive-Diary.git`、または「Code → Download ZIP」して展開）
2. Chrome で `chrome://extensions`（Vivaldi は `vivaldi://extensions`）を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ ダウンロードしたフォルダを選択
5. ツールバーのパズルアイコンからピン留めすると使いやすくなります

更新するときは `git pull`（または ZIP を上書き）して、拡張機能の管理ページで「再読み込み」を押してください。

> フォルダの場所を変えると拡張機能 ID が変わり、Drive 連携の再設定が必要になります。

## Google ドライブ連携の設定

日報は `マイドライブ/タブ日報/2026-11-24.md` のように 1 日 1 ファイルで保存され、変更があった日だけ自動で上書き更新されます（初期値 60 分ごと）。
権限は `drive.file`（**この拡張機能が作ったファイルにしかアクセスできない**）だけを使います。

Google Cloud で OAuth クライアント ID を 1 つ作成する必要があります（無料）。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」→ **Google Drive API** を有効化
3. 「OAuth 同意画面」を設定
   - ユーザーの種類: 外部 / アプリ名: 任意
   - スコープ: `.../auth/drive.file` を追加
   - テストユーザー: 自分の Google アカウントを追加
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - 種類: **ウェブ アプリケーション**
   - 承認済みのリダイレクト URI: 拡張機能の **設定** 画面に表示される `https://<拡張機能ID>.chromiumapp.org/` を貼り付け
5. 作成されたクライアント ID を拡張機能の **設定 → OAuth クライアントID** に貼り付け
6. 「Google ドライブに接続」→ Google の画面で許可

### 複数の PC で使う

同じ日に複数の PC で使っても、**1 日 1 ファイルのまま PC ごとのセクションに分けて**記録がまとまります。
保存のたびに Drive 上のファイルを読み込み、自分の PC のセクションだけを差し替えるので、他の PC の記録は消えません。

```markdown
# タブ日報 2026-11-24（火）

<!-- device:xxxx:start -->
## 🖥 自宅
…自宅 PC の閲覧ページ・アーカイブ…
<!-- device:xxxx:end -->

---

<!-- device:yyyy:start -->
## 🖥 会社
…会社 PC の閲覧ページ・アーカイブ…
<!-- device:yyyy:end -->
```

2 台目の PC の設定:

1. 2 台目にも拡張機能をインストールし、設定画面に表示される **リダイレクトURI** を、同じ OAuth クライアントの「承認済みのリダイレクト URI」に**追加**（1 台目の分は残す）
2. 同じ **クライアントID** を貼り付け、**この PC の名前**（例: 会社）を入れて「Google ドライブに接続」

- `<!-- device:… -->` の行は区切りの目印です。Drive 上でファイルを手で編集する場合は、この行を消さないでください。
- 2 台がまったく同時に保存した場合のみ、片方の更新が一度だけ反映されないことがあります（次回の自動同期で戻ります）。
- お気に入り・アーカイブ・よく見るは PC ごとに別管理です。

### 別の方法（Chrome 拡張機能タイプのクライアント）

手順 4 で種類を **Chrome 拡張機能** にし、アイテム ID に拡張機能 ID を入れた場合は、`manifest.json` に次を追加して拡張機能を再読み込みしてください。Chrome のログインアカウントで認証され、トークン更新がより安定します。

```json
"oauth2": {
  "client_id": "xxxxxxxx.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/drive.file"]
}
```

### うまく同期できないとき

- 日報画面または設定画面に「Google への再接続が必要です」と出たら、設定 →「再接続」を押してください（ウェブアプリ方式は Google のログイン状態を使ってバックグラウンドでトークンを更新するため、ログアウトすると再接続が必要です）。
- OAuth 同意画面が「テスト」状態だと、一定期間で再同意を求められることがあります。

## データについて

- すべてのデータはブラウザ内（`chrome.storage.local`）に保存されます。外部に送られるのは Drive 連携をオンにした場合の日報ファイルだけです。
- 記録対象は `http(s)://` のページのみ。同じページを 30 秒以内に何度開いても 1 回と数えます。
- 設定 →「すべてのデータを書き出す」で JSON バックアップを取れます。

## ファイル構成

```
manifest.json     拡張機能の定義（Manifest V3）
background.js     放置検知・自動アーカイブ・閲覧記録・Drive 同期
app.html/js/css   ポップアップ兼管理画面
lib/common.js     設定・日付・共通処理
lib/report.js     日報データ集計と Markdown 生成
lib/drive.js      Google Drive API（認証・フォルダ作成・アップロード）
icons/            アイコン
```
